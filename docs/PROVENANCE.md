# Source and media provenance

This is an extraction of original Ghost Director application work, developed alongside Studio OS, with a curated visual report. It does not copy Studio OS Git history, private production folders or inherited persona/skill libraries. Selected documentation images and videos are included under `docs/media`; the experiment databases and full generated-media bundles remain excluded. The application scope is recorded in `LICENSE-GHOST-DIRECTOR.md`; root `LICENSE` is MIT for the published original application. `SOURCE-INVENTORY.json` identifies the extracted application file hashes before standalone packaging adjustments.

Original bundled role contracts under `ghost_director/studio/contracts/` were authored for the public application. They are not copies of private Studio OS prompts or vendor skills. An optional external checkout is obtained and licensed separately by its user. Runtime records distinguish bundled contracts from external context and retain file hashes.

## Dated provider capabilities

As of the November 3, 2026 project checks, the app pins Meta `muse-wonder-1.0`, `muse-image-1.0`, and `sam-3.1`; hosted reconstruction uses `fal-ai/sam-3/3d-objects`. The reference-motion video adapter is `bytedance/seedance-2.5/reference-to-video` through fal. Legacy endpoint/reference routes remain separately attributed in code. No model weights are bundled. These pins are compatibility records, not a claim that all endpoints remain available or globally newest.

Official references: [Meta models](https://dev.meta.ai/docs/models), [Meta image generation](https://dev.meta.ai/docs/image-generation), [SAM 3D Objects](https://fal.ai/models/fal-ai/sam-3/3d-objects), [image-plus-motion route](https://fal.ai/models/bytedance/seedance-2.5/reference-to-video).

The fresh experiment used three Meta image requests and two hosted SAM requests. Its $0.07 is an application-ledger estimate using published rates, not an audited provider invoice. Human likeness, material quality and hidden surfaces require inspection. No finished movie from that scene is included or claimed.

## Curated visual report

The [visual tour](SHOWCASE.md) contains actual application captures made on November 4, 2026, the three original Conservator reference images, the actual 12-second Blender motion output and a separately labeled earlier amber-bottle video. The walkthrough is an inspection of completed work, not a timed generation demonstration. No role tasks were run in that fresh production capture. The earlier prop-only take remains unaccepted and has incomplete scene appearance coverage; it is not a Conservator film.

The [media manifest](media/manifest.json) records byte sizes, SHA-256 hashes, source identities and transformations. Screenshots and original reference PNGs are copied without visual modification. The real-time screen recording is transcoded to H.264 for browser playback; the README preview is accelerated 4.5× and reduced in size/frame rate. The two output MP4s preserve their original bytes. GIF previews are reduced-frame-rate derivatives, not new model results.

The [standalone HTML report](showcase/index.html) uses relative files and no remote fonts, trackers, embeds or API keys. GitHub Pages serves it at https://muratcankoylan.github.io/ghost-director/showcase/. It can also be opened from a clone/download, or the `docs` directory can be served with a local HTTP server. The Markdown tour remains directly readable on GitHub. Media publication does not populate a new application installation or include the private production database.

## What is excluded

Credentials, `.env.local`, SQLite/WAL files, provider request/response bodies, signed URLs, unselected production media, private screenshots and local machine paths are excluded. The empty starter architecture is generated by original code. Historical experiment builders may refer to omitted source textures; use `bootstrap` for a fresh checkout.

Blender, FFmpeg, JavaScript and Python packages retain upstream licenses. Generated media remains subject to applicable provider terms and is not relicensed merely because the application is MIT. The optional demo export/import tools produce a separately selected, sanitized bundle; exporting is not by itself public-release approval or a new media license.
